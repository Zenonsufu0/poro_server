# 공통 도메인 — 명령어

> **[도메인: 공통]** — 특정 게임(RPG/Zenon Mon)에 종속되지 않는 봇 전역 기능.
> 코드: `modules/common/`.

## 명령어

| 명령어 | 설명 | 상태 |
|---|---|---|
| `/핑` | 봇 응답 지연(latency, ms) 확인 (ephemeral) | 🟢 구현 (`general.py`) |
| `/도움말` | 사용 가능한 명령어 안내(도메인별 그룹, ephemeral) | 🟢 구현 (`general.py`) |

### `/도움말` 구현 노트 (2026-07-02)
- app command 트리(`bot.tree.walk_commands()`)를 순회해 **명령 이름·설명을 실제 트리에서 읽어** 도메인별로 그룹핑 → 별도 카탈로그 없이 명령 추가 시 자동 반영(drift 없음).
- 도메인 그룹 = 명령이 정의된 모듈 경로(`modules.<domain>.*`) 기준.
- **권한 필터:** 운영 권한 명령(`requires_permission`)은 `requires_permission` 이 콜백에 심는 `_perm_keys` 를 읽어 `member_has_permission` 으로 판정, **보유자에게만 노출**. 공통 명령은 항상 표시. (가시성 정책 §10 정합 — 접근역할은 디스코드 측 가시성이라 봇 필터 대상 아님, 권한 역할만 필터)
- 필드 value 1024자 초과 시 `(계속)` 필드로 청크 분할. 명령 트리 순회라 카테고리/서버상태 게이팅과 무관.
